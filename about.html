💬 关于本项目

社区项目 · 零成本运营

🎯 我们想做什么

一个服务于国服 DOTA2 新玩家的社区平台：从「国服怎么注册/启动」到 「怎么选英雄 / 怎么变强」，用轻量的网页工具 + 社区内容 + OpenDota 免费数据实现。 目标排序：① 帮新玩家入坑 → ② 提升国服整体水平 → ③ 可持续（仅覆盖成本）。

🌱 为什么做这个

官方新手教程长期被社区公认过时/断链；全球也没有一款产品主攻「国服新手全流程」。 我们相信帮助新玩家顺利入坑本身就是价值，因此内容以社区共创为主、无广告、无商业采集。

🔧 技术栈

纯静态 HTML/CSS/JS（零构建工具、零后端），托管在 GitHub Pages 免费层。 数据由 scripts/fetch_hero_data.py 定时抓取 OpenDota API 生成 JSON，全程近乎零成本。

📡 数据来源与准确性

数据类型来源更新方式说明
英雄胜率 / 出场 / 职业数据 OpenDota API（heroStats 接口） 脚本定时抓取（约每天 1 次） 免费层约 60 次/分、3000 次/天，足够本平台使用
版本补丁信息 官方补丁日志 + 社区解析 人工更新 见新手指引 / 周报正文
新手指引内容 完美世界官方公告 + 社区实践 人工维护 非官方，仅供参考

📄 免责声明

  1. 非官方平台：本站为社区项目，与 Valve、完美世界及其关联公司无任何隶属或赞助关系。
  2. 数据时效：所有胜率/出场数据为抓取时点快照，随时间波动，不构成稳定的游戏建议。
  3. 内容参考：新手指引整理自公开资料与社区实践，官方流程如有变动请以官方最新公告为准。
  4. 游戏风险：任何游戏都有竞技压力，请理性游戏、健康生活，远离代练与账号交易。
